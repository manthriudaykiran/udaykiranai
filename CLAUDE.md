# Uday Kiran Brand System — Claude Code Guidelines

## Visual Identity Default
All future UI, presentation slides, social graphics, and digital experiences must adhere to the **Uday Kiran Premium Brand Design System**:

- **Creator:** Uday Kiran
- **Public Brand:** Uday Kiran | Practical AI
- **Business Brand:** KiranForge
- **Tagline:** Make AI Simple. Practical. Useful.
- **Watermark:** "Created by Uday Kiran" (for presentations and downloadable graphics)

## Canonical Color Tokens
- Primary:

  - Sunset Orange: `#FB6A21`
  - Vibrant Coral: `#FF4D6D`
  - Electric Magenta: `#D946EF`
  - Royal Violet: `#7C3AED`
- Neutrals:
  - Midnight Navy: `#071426` (Primary dark canvas)
